Well, one thing. You can easily ask questions, like, what are the continued fraction expansions of sqrt(n) for various n? The "greats" all calculated these by hand: Euler, Legendre, Lagrange, Fermat, Galois.... I just used Claude.

√7 = [2; 1, 1, 1, 4]
√13 = [3; 1, 1, 1, 1, 6]
√19 = [4; 2, 1, 3, 1, 2, 8]
√31 = [5; 1, 1, 3, 5, 3, 1, 1, 10]
√61 = [7; 1, 4, 3, 1, 2, 2, 1, 3, 4, 1, 14]
√94 = [9; 1, 2, 3, 1, 1, 5, 1, 8, 1, 5, 1, 1, 3, 2, 1, 18]

It turns out every continued fraction of sqrt(n) is of the form:

[a0; a1, a2, ... aL, 2a0]

where the sequence after the semicolon repeats itself indefinitely and the sequence a1, a2, ..., aL is a palindrome.

The palindrome part of our examples:

1, 1, 1
1, 1, 1, 1
2, 1, 3, 1, 2
1, 1, 3, 5, 3, 1, 1
1, 4, 3, 1, 2, 2, 1, 3, 4, 1
1, 2, 3, 1, 1, 5, 1, 8, 1, 5, 1, 1, 3, 2, 1

This is surprisingly "fiddly" to prove, even though it is only "elementary" techniques.
