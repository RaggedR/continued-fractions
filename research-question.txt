WHEN IS THE SUPREMUM ATTAINED?
A question left open by all-the-proofs.tex §7 on 3 October 2026, and narrowed
the same day.  attainment.py holds the checks; nothing below is eyeballed.


THE OBSERVATION

thm:step5 recovers the intercept as a formula,

    x = sup_{N >= 0} D(N),    D(N) = S(N) - N alpha,

where S(N) counts the 1s in the first N letters.  The theorem then splits on
whether that supremum is attained:

    attained                 l = C(alpha, x)
    not attained, x < 1      l = C+(alpha, x)
    not attained, x = 1      l = C+(alpha, 0)

thm:counterex -- the sequence 1c, which is Sturmian and is no lower coding --
is the third case.  It is not a separate pathology; it is the extreme point of
the same phenomenon.  Attainment is what decides which of the two codings a
Sturmian sequence is, and it is why thm:mh has to offer both.


SETTLED: THE CLOSED FORM

For l = C(alpha, x) with x in [0,1), S(N) = floor(alpha N + x) - floor(x), so

    D(N) = x - {alpha N + x},

the orbit {alpha N + x} is dense, and sup D = x whatever x is.  So

    the supremum is attained  <=>  {alpha N + x} = 0 for some N >= 0
                              <=>  x = {-N alpha} for some N >= 0,

the backward orbit of 0 under rotation by alpha -- which is exactly the set of
intercepts where C and C+ differ.  The N is unique, so:

    sup_M D(M) is attained at M = N and at no other index.           [check A]

That sharpens thm:step5's attained case, which says only that some index
works.  It is not in the paper and has no Lean counterpart, so §11 still reads
"Nothing" and should keep reading it until one is written.

So the content was never the equivalence.  It is the translation of "x lies in
the backward orbit of 0" into the tower.


SETTLED: THE LITERATURE

The parametrisation exists.  C. Wojcik, "Formal Intercept of Sturmian words",
arXiv:1803.02073 (2018, preprint, no journal reference), gives the second
parameter a combinatorial definition as an infinite Ostrowski expansion.
Definition 12 there sets

    I_alpha = { (k_n)_{n>0} : k_n in [0, q_n), k_n = k_{n+1} mod q_n }

with q_n the continuants of alpha, and Proposition 12 is a bijection between
Sturmian words of slope alpha and I_alpha.  Proposition 8 gives the
admissibility conditions on the digits: 0 <= b_1 <= a_1 - 1, 0 <= b_i <= a_i,
and b_{i+1} = a_{i+1} forces b_i = 0.  Our (k0_j) satisfies them.

The paper never names the lower/upper distinction: the character for a ceiling
does not occur in it.  But Proposition 12 builds the intercept from shifts of
the characteristic word, rho_n = min{k >= 0 : x and T^k(c_alpha) agree to
length q_n - 1}, which is the same two-sided-window picture used below.  So the
framework plausibly already determines the answer without stating it, and the
proofs of Propositions 9 to 12 are where to look first.  At an orbit point
there are two Sturmian words, and the digit sequence has to be telling them
apart.

I_alpha is the inverse limit lim Z/q_n, an alpha-adic completion of Z, and the
two codings sit on the copy of Z inside it.  Telling a lower coding from an
upper one is telling N >= 0 from its partner, which in Z_p needs the whole
expansion -- not a window of it, and not a tail.  The numerics say exactly
that.


NARROWED: WHAT A CHARACTERISATION CANNOT BE

Attainment is a function of the tower, since the tower is a complete invariant.
It is not a function of any tail of it, and not a function of any bounded
window.

  * At n = 2 and n = 5 the characteristic word and 1c have towers that agree
    from level 2 on:                                                [check C]

        n = 5    C (alpha, 0)   k0_j = 4 3 3 3 3 3 3 ...
                 C+(alpha, 0)   k0_j = 0 4 3 3 3 3 3 ...

    One is attained and one is not.  A tail condition on (eps_j, a_j, k0_j)
    cannot separate them.

  * The deepest agreement between an attained and a non-attained tower grows
    with the range of shifts searched -- 2, 4, 6 levels at n = 2 for shifts
    below 8, 30, 120.                                               [check D]

    So no criterion reading finitely many levels can be right.

The two negative results have one cause.  C and C+ are windows on the same
two-sided coding, which agree off {-1, 0}: one reads 10 there and the other
01.  The whole dichotomy is a single transposition at the seam, so the two
derivations converge once the derivation has passed it -- at a level that
recedes as the window starts further left.


KILLED: DO NOT RETRY

  * k0_j = a_j for all j.  This was the file's own first conjecture.  At n = 3
    and n = 7 the characteristic word -- attained, intercept 0 -- has k0_j = 0
    at every level.                                                 [check E]
  * "(k0_j) eventually 0" and "(k0_j) eventually a_j", the two degenerate
    Ostrowski tails.  Both are tail conditions; check C rules the shape out.
    At n = 3 they do separate C from C+, which is what makes the shape look
    right; at n = 2 and n = 5 they do not.  The difference is eps: when
    eps_j = 0 at every level the two tails coincide.
  * Rational intercepts as a test family.  For rational x only x = 0 lies in
    the orbit, so every other rational is non-attained and carries no
    information about the attained side.  attainment.py tests windows on the
    two-sided coding instead.


WHAT IS LEFT

Read the whole of (eps_j, a_j, k0_j) and decide lower or upper.  The data says
every orbit tower has the form

    [finitely many levels encoding N]  [a_J, then a-1 repeating]

and that the unattained one at the same intercept carries one extra level
before the marker.  The question is now: where is the marker, and what is the
parity or offset that distinguishes the two?  That is a question about
normalisation of Ostrowski representations, not about Sturmian words, and it is
the half arXiv:1803.02073 does not do.

Both halves of the dichotomy can be generated to order by attainment.py, so a
conjecture can be tested in seconds against the same definitions the theorem
uses.
